Octofitter.jl

Octofitter is a Julia package for performing Bayesian inference
against a wide variety of exoplanet / binary star data.
You can also use Octofitter from Python using octofitterpy.

Read the tutorials and documentation here.

Read the paper

In addition to these documentation and tutorial pages, you can read the paper published in the Astronomical Journal (open-access).
