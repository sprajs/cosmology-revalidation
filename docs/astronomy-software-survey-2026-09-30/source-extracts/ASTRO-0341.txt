sunkit-image

An image processing toolbox for Solar Physics.

Currently this is an experimental library for solar physics specific image processing routines.
Ideally it will only contain routines that have been published in the literature.

See sunkit-image Documentation for instructions on how to install and contribute.

Usage of Generative AI

We expect authentic engagement in our community.
Do not post the output from Large Language Models or similar generative AI as code, issues or comments on GitHub or any other platform.
If you use generative AI tools as an aid in developing code or documentation changes, ensure that you fully understand the proposed changes and can explain why they are the correct approach and an improvement to the current state.
For more information see our documentation on fair and appropriate AI usage.

Contributing

We love contributions! sunkit-image is open source,
built on open source, and we'd love to have you hang out in our community.

If you would like to get involved, check out the Developers Guide section of the SunPy docs.
Stop by our chat room #sunpy:openastronomy.org if you have any questions.
Help is always welcome so let us know what you like to work on, or check out the issues page for the list of known outstanding items.

For more information on contributing to SunPy, please read our Newcomers' guide.

When you are interacting with the SunPy community you are asked at to follow our code of conduct.
