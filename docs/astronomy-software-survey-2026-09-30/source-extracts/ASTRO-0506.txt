MPI for Python

Overview

This package provides Python bindings for the Message Passing
Interface (MPI) standard. It is
implemented on top of the MPI specification and exposes an API which
grounds on the standard MPI-2 C++ bindings.

Prerequisites

Python 3.10 or above,
or PyPy 7.3 or above.

An MPI implementation like MPICH or
Open MPI built with shared/dynamic
libraries.
