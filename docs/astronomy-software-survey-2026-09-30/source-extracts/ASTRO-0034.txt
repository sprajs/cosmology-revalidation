 Note that users with exsiting SSWIDL installations
may upgrade or install new libraries using the 

ssw_upgrade procedure ssw_upgrade.pro, now w/more WGET 

e.g., you don't need this FORM
to ADD new branches to an existing installation

 (This use of ssw_upgrade.pro to add new libraries applies to any new branch/library to 
an existing installation)

For example, cut&paste the following orange line into your sswidl session
to upgrade or install aia,wispr,stix
(ssw_upgrade only does something useful if run by Owner of local $SSW installation) 

 IDL> ssw_upgrade, /aia,/wispr,/stix,/spawn, /loud, /WGET

ssw_upgrade will also install or upgrade required SSW dependencies; in the case the ontology package is included, since that library includes shared sswidl utilities for 
JSOC and HEK/HCR communications as well as SDO access and read utilities; 
above call would also include mission/gen library dependencies for SDO, Parker Solar Probe, and Solar Orbiter
