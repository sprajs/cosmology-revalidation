GRTeclyn

GRTeclyn is a new numerical relativity code developed by the GRTL Collaboration that is actively being upgraded with new features (see our website for the full list). It is a port of the GRChombo code (based on the Chombo libraries) to the AMReX library in order to leverage AMReX's support for GPUs and ongoing active development.

The AMReX documentation can be found here.

The name follows a similar pattern to GRChombo, namely "GR" + "<Tool in a foreign language>". In this case, "Teclyn" is a Welsh word for "Tool".
