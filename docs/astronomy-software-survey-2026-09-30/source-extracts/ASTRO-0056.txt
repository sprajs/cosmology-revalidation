ISIS

 IMAGE SUBTRACTION

PACKAGE

 ISIS
is a complete package to process CCD images using
the image subtraction method:

  Image
subtraction using constant kernel

  Alard
& Lupton 1998, ApJ, v. 503, p. 325

Image subtraction using spacially
variable kernel

  Alard  2000, A&A
in press

  ISIS contains
3 sub-packages, and allows to build light curves of variables objects from
a series of CCD images
