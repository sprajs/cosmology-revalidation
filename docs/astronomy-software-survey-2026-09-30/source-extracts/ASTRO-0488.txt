RH 1.5D

RH 1.5D is an open source, massively-parallel radiative transfer code for spectral synthesis in stellar atmospheres. It is a modified version of the RH code by Han Uitenbroek.

For detailed installation and running instructions, please see the online documentation at https://ita-solar.github.io/rh/. RH 1.5D depends on two external libraries: MPI and HDF5.

RH 1.5D is also documented in the paper by Pereira & Uitenbroek, 2015, A&A, 576. If you use RH 1.5D for your work, we would appreciate if you would acknowledge it by citing its paper and also the RH paper of Uitenbroek, 2001, ApJ, 557. In addition, if the journal allows it please include a link to this repository.
