LePHARE 
 PHotometric Analysis for Redshift Estimation 

LePHARE is a code for estimating galaxy redshifts and physical parameters using template fitting. It is a complete rewrite in C++ of the Fortran code, with python binding and extension using pybind11.

Please find the code documentation here, including how to install it and to get started.
