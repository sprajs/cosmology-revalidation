README

More items

Compiling:

 $ make

To run the code:

 $ ./Exo_Transmit

To undo compiling or delete object files:

 $ make clean

For additional information on compiling and running the program see 
USR_MANUAL.txt 

When publishing results based on usage of Exo-Transmit please cite:
Kempton, E. M.-R., Lupu, R. E., Owusu-Asare, A., Slough, P., & Cale, B., 2017, PASP, 129, 044402 (https://ui.adsabs.harvard.edu/abs/2017PASP..129d4402K/abstract)

If using the opacity data included with Exo-Transmit please additionall cite the following three papers:
Freedman, R. S., Marley, M. S., & Lodders, K., 2008, ApJS, 174, 504-513 (http://adsabs.harvard.edu/abs/2008ApJS..174..504F)
Freedman, R. S., Lustig-Yaeger, J., Fortney, J. J., et al., 2014, ApJS, 214, 25 (http://adsabs.harvard.edu/abs/2014ApJS..214...25F)
Lupu, R. E., Zahnle, K., Marley, M. S., et al., 2014, ApJ, 784, 27 (http://adsabs.harvard.edu/abs/2014ApJ...784...27L)
