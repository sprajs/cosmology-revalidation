Abstract

The Sub-Millimetre User Reduction Facility (Smurf) is a software package for initial reduction of data
produced by the ACSIS correlator and the SCUBA-2 bolometer array on the James Clerk Maxwell
Telescope (JCMT). This document describes the Smurf tasks used to process raw ACSIS data into data
cubes, and raw SCUBA-2 data into images. These low-level tasks are used within automated
Orac-dr pipelines (documented elsewhere) that produce calibrated data products. This document is
intended for users who wish to run the low-level tasks themselves, to explore possibilities not
provided by the automated pipelines.
