# Released distances and expansion

## Question

What expansion histories fit the released corrected supernova magnitudes and compressed BAO measurements under explicit geometry, covariance and evolution assumptions?

`cosmology` supports flat LCDM, constant-w, CPL, a two-parameter kinematic history, and piecewise-constant deceleration bins. BAO/joint fits use the retained CPL parameterization with a free `H0_rd` scale. These calculations start downstream of light-curve training, standardization, calibration and selection corrections.

## Calculation

Let `E(z)=H(z)/H0` and `D(z)=integral_0^z dz'/E(z')`. The supernova prediction is `5 log10[(1+zHEL)D(zHD)]`, with the common magnitude offset eliminated analytically. For covariance `C`, the offset-marginalized quadratic form uses

`A = C^-1 - (C^-1 1)(1^T C^-1)/(1^T C^-1 1)`.

The input covariance has tiny printed antisymmetric roundoff; the code first checks it is below `1e-7 mag²`, then symmetrizes. The sample uses `zHD > 0.01`. The full covariance is preserved, including repeated distance rows; physical-CID count and row count are reported separately.

CPL uses `w(z)=w0+wa*z/(1+z)` and a flat, radiation-free late-time expansion. The prior requires `w0+wa<0`. The kinematic family is `q(z)=q0+q1*z/(1+z)`. Piecewise-q models integrate analytically within `[0,0.1,0.3,0.6,1,2.5]`; the first parameter is an interval value, not independently resolved instantaneous `q(0)`.

Distances use 48-point Gauss–Legendre integration where applicable. Forty interpolation nodes per q interval compress repeated likelihood evaluations. Independent Astropy distances, constant-q analytic integrals and the uncompressed likelihood check the implementation. A mode-level compressed/full chi-square difference above `0.01` stops the run.

## Reproduction

```bash
uv run --frozen python research.py run cosmology --name baseline
uv run --frozen python research.py run cosmology --name joint --config configs/joint-cpl.json
uv run --frozen python research.py run cosmology --name qbins --config configs/qbins.json
```

Default LCDM: seed 41001, 40 walkers, 7,000 steps, 1,500 burn-in steps, four optimizer starts and `0.01 < Omega_m < 0.99`. Other parameter bounds and active priors are written to `priors.json`. Chains are always retained; posterior summaries require finite positive autocorrelation times and at least 50 retained autocorrelation lengths per parameter. This is a within-ensemble gate; independent seeds and model sensitivity remain additional checks.

The baseline should give `Omega_m` near `0.33158`, chi-square near `1402.9191`, and model-extrapolated `q0` near `-0.5026` at the mode. The seeded posterior has mean q0 about `-0.5015` and SD about `0.02725`. These are conditional released-product results, not evidence that upstream corrections have been independently identified.

An optional explicit CSV with columns `z,delta_mu` supplies an evolution sensitivity. Amplitude options are `fixed`, `uniform`, or `normal` with mean 1 and SD `4/30`; the broad amplitude bounds are `[-2,4]`. Positive `delta_mu` is subtracted from the released magnitude relative to the baseline model. The template must cover the full SN redshift support. The [population workflow](populations.md) can generate a stated SFH/DTD template; it does not estimate an additional empirical correction.

## BAO shape constraint

`bao-shape` uses six anisotropic DR2 redshift pairs, excluding the isotropic BGS `DV` row. Under flat geometry, write `t=ln(1+z)`, `g=(1+z)DH/rd` and `D=DM/rd`. Nonacceleration over the sampled intervals requires nonnegative, nonincreasing `g`, with distance increments bounded by its adjacent endpoint values. A cone generated by step functions expresses those inequalities.

Two constrained solvers must agree and satisfy the optimality conditions. The default observed squared distance to the cone is approximately `11.4670671`. The 5,000-draw Gaussian apex simulation gives a dominating tail near `0.42`; its binomial interval is reported. This is a conservative composite-shape calculation, not a direct measurement of present q0 and not a flatness-free or sound-horizon-free empirical proof.
