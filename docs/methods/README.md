# Methods

Read these in measurement order. Each chapter states the input level, assumptions, calculation, expected outputs and interpretation limits.

1. [Inputs and reproducibility](data.md): acquisition, hashes and output contracts.
2. [HST imaging](hst.md) and [dark measurements](hst-dark.md): detector reads, geometric weights and repeat statistics.
3. [CSP photometry](csp.md): original rows, filter identities and photon integrals.
4. [DES light curves and calibration](des.md): flux fits, predictive comparisons and shared calibration modes.
5. [RAISIN infrared measurements](raisin.md): paired distance branches, timing and signed baselines.
6. [Ages and populations](populations.md): extraction, conditional regression and delay distributions.
7. [Constructed dust and selection models](constructed-models.md): controlled mathematical examples.
8. [Distances and expansion](distances.md): released-distance likelihoods and BAO constraints.

For commands use the [workflow guide](../workflows.md). For independent checks use [validation](../../validation/README.md). Physical derivations are collected under [physical foundations](../physics/README.md).
