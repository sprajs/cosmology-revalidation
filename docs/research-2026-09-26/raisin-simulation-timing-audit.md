# Archived DES simulation FITRES timing audit

Two nominal compressed FITRES files from the pinned author commit `b888214a5cbae38ac0bf886488ce7734f5b77e87` were acquired without photometry or LCPLOT: [NIR](../../runs/research_2026_09_26/raisin_simulation_execution_review/nominal_fitres/nir.FITRES.gz) (Git blob `7dd16e0978e2be4f09ebdc14698aaeca902df26e`) and [optical+NIR](../../runs/research_2026_09_26/raisin_simulation_execution_review/nominal_fitres/optnir.FITRES.gz) (`53b5efe4c8804b19873b427fba27e0eb70aad0ed`). Both compressed bytes passed the repository tree's exact Git blob and size checks; SHA-256 hashes are in the [acquisition manifest](../../runs/research_2026_09_26/raisin_simulation_execution_review/nominal_fitres/acquisition.json). Both headers state `VERSION_SNANA = v11_04k`, `VERSION_PHOTOMETRY = DES_RAISIN_SIM`, and `SNANA_VERSION : v11_04k`.

The [protocol](../../runs/research_2026_09_26/raisin_simulation_execution_review/nominal_fitres/timing-audit-protocol.json) was saved and SHA-256 frozen as `3697ece51ac4ce3c7ff0cccbb79f92c81b3d1cb25dbeec52363647b6e30d0838` after header/schema inspection and before numeric rows were read. All `SN:` rows were retained. The audit used printed `SIM_PKMJD` as generating peak, `PKMJDINI` as fit initializer, and `PKMJD` as fitted peak. All three columns print four decimal days, so each paired difference has roughly 0.0001-day quantization. Decimal arithmetic was used for the differences, and an independent standard-library parser recomputed the primary means and population SDs. Full strata, quantiles, error categories, and precision counts are in [timing-result.json](../../runs/research_2026_09_26/raisin_simulation_execution_review/nominal_fitres/timing-result.json).

All 30,000 NIR and 29,987 optical+NIR rows have finite, nonsentinel values in these three timing columns and `ERRFLAG_FIT=0`. `CUTFLAG_SNANA=3` in every row; this audit assigns no selection meaning to that flag. The NIR initializer-minus-truth range is −0.0430 to +0.0469 days; 20,108/30,000 are within ±0.01 days and 29,892/30,000 within ±0.03 days. The optical+NIR fitted-minus-truth range is −8.0274 to +2.6719 days, with median −0.0078 and median absolute deviation 0.1914 days. These are descriptive output distributions, not quality-selected or bias-corrected distances.

The 29,987 common CIDs have identical printed `PKMJDINI` values in both files and identical `SIM_PKMJD`, `SIM_LIBID`, `SIM_TYPE_INDEX`, `SIM_STRETCH`, and `SIM_AV`; no optical+NIR-only CID exists. Thirteen NIR-only CIDs are recorded by [the result](../../runs/research_2026_09_26/raisin_simulation_execution_review/nominal_fitres/timing-result.json). On common CIDs, optical+NIR fitted peak minus NIR fitted peak has mean −0.066666 day and population SD 0.545432 day. The optical fit was **not** used as simulation truth.

The source mechanism is compatible with the directly observed NIR distribution. The pinned generator input specifies `GENSIGMA_SEARCH_PEAKMJD: 0.01`; v11_04k [`snlc_sim.c`](../../sources/repos/RickKessler__SNANA@v11_04k/src/snlc_sim.c:13837) computes `PEAKMJD_SMEAR = GENLC.PEAKMJD + Gaussian × GENSIGMA_PEAKMJD` and copies it to `SNDATA.SEARCH_PEAKMJD` at line 21604. v11_04k [`snlc_fit.car`](../../sources/repos/RickKessler__SNANA@v11_04k/src/snlc_fit.car:8103) initializes the peak parameter from `SNLC_SEARCH_PEAKMJD`; the archived NIR NML fixes the peak step at zero. Thus its 0.010103-day SD around `SIM_PKMJD`, exact fitted/initializer equality, and zero printed peak error are mutually consistent with the near-truth 0.01-day mechanism. This is a source-and-output consistency check. The historical generator completion/seed and run-time input hash link remains absent, and a v11_04k header does not by itself prove the exact checked-out source commit was the compiled executable.
