independent observational tests ahead of cosmological parameter fitting.
The [programme status map](programme-status.md) locates every E00–E17 direction
and its next unresolved gate.

locates corrections already present at each stage and the tests still needed
before an additional correction can be propagated.
GPT-6 Astra supplies scientific design and independent challenge; instructed
GPT-6 Sol researchers handle the numerical and selection workstreams.

The strongest current concerns are upstream of cosmology: verified
sign-dependent epoch omission, weakly identified template/distance branches,
near-truth timing in archived infrared bias simulations, and a traced
WIRC J/RetroCam RC1 passband mismatch in the low-redshift inputs. The timing now
has direct output evidence in the latest 2022 table: 30,000 NIR simulated fits fix peak time with
0.0101day scatter around generating truth, while the corresponding free
optical+NIR fits have 0.545day scatter. These are concrete procedures to
test and propagate; they are not yet measured cosmological corrections.
