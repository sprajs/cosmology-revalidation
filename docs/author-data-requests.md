Release of executable configurations with immutable input hashes would be preferable to prose descriptions alone.

For a new observational programme, the high-value measurement is a held-out, selection-characterized luminosity residual conditioned jointly on local age, metallicity and sightline dust, with UV–MIR/spectroscopic host information and optical/NIR SN data across redshift. Its value would come from predictive information independent of the distance-calibration model being tested, not from combining nominal significances from overlapping catalogues.
