# Read-only verification of calibration and foreground pilots

> Supporting research note. Scientific findings and limitations are preserved from the recorded investigation; historical result links identify the evidence available at that time. See the [study guide](../../README.md) for current execution status.

## Concrete provenance gap and repair

The original manifests for the nonlinear foreground refit, stellar-extinction branch test, and stellar-to-SN transfer hash their executed source and inputs, but **do not hash their saved outputs**. Their current files cannot be certified as unchanged since generation from those original manifests alone. I left those manifests and all analyses untouched. The separate [post-run verification manifest](https://github.com/sprajs/cosmology-revalidation/blob/17487bf659fcbdeeea072221492bac14b04a0a85/runs/research_2026_09_26/calibration_verification/manifest.json) now hashes every currently saved file in each of the three run directories, records the matching original source/input hashes, and saves independent numerical checks. These are hashes of the **verified current checkpoint**, captured on 26 September 2026 after the runs; they must not be described as hashes captured when the runs were generated. The foreground-map main manifest already had four output hashes, all of which match the current files. No mismatched input or executed-source hash was found in any of the four checked runs.

## Source and numerical checks

The local CSFD-v2 `readme.txt` defines mask bit 0 as the LSS-correction footprint and bit 2 as the cosmology-reliability region. All three source FITS maps are `NSIDE=2048`, `ORDERING=RING`. Independently resampling the mask reproduces all 64 saved nearest-pixel values and both four-neighbor flags: 48 objects are reliable and all 64 lie in the correction footprint. The cleaning, resampling, and direct-replacement map modes obey their saved additive identity to less than 9e-17 in E(B-V). The release HEAD `MWEBV` column is FITS big-endian float32 (`>f4`), and the saved CSV differs from its direct value by at most 1.0e-9. The successful nonlinear refit rereads HEAD FITS values, avoiding the earlier archived CSV-roundtrip failure. The parent analysis already treats HEAD as 0.86-scaled; an additional universal factor would be double application.

The signed perturbations are internally consistent. For a change in **model** foreground E(B-V) at fixed observed flux, the local fitted parameter response is `-R ΔE` and the projected log-likelihood gain is `r⊥·G⊥ΔE − ||G⊥ΔE||²/2`. For a positive correction added to **observed magnitude**, the fitted response is `+R Δm` and the gain is `−r⊥·G⊥Δm − ||G⊥Δm||²/2`. An independent SVD projector, instead of the generation code's QR projector, reproduced all 384 foreground response rows and 256 stellar-transfer rows: largest absolute discrepancies were 9.1e-17 mag for foreground shift, 7.9e-15 in its fixed gain, 1.0e-16 mag for stellar shift, and 4.4e-16 in its fixed gain. The four-band gray response equals `[1,0,0,0]` to 1.5e-9; a common zero-point mode is absorbed by fitted amplitude and cannot be inferred from the projected residual score. The NGSL and CALSPEC fixed branch vectors contain gray components of -1.046 and -0.498 mmag respectively, so their absolute mean distance shifts require the stated fixed-vector convention.

The stellar source has 1,255 distinct RA/Dec rows. The DES and PS1 synthetic files each have 451 unique `standard`/category joins; all 451 pair one-to-one. The fixed observed-cut intersection is 1,178 rows, matching the saved selection and summary. The stored-extinction input file was already selected upstream; zeroing extinction here cannot restore missing raw stars. Its internal held-out set occupies only two sky cells, so its small residual difference does not validate a survey-wide zero point or establish which Dovekie branch generated the published calibration. The source raw `abs(DES−PS1)<1` per-band cut is reflected in the descriptive test. A fixed synthetic-minus-observed branch vector is a sensitivity direction, not a measured required SN correction.

The [paired nonlinear refit](https://github.com/sprajs/cosmology-revalidation/blob/17487bf659fcbdeeea072221492bac14b04a0a85/runs/research_2026_09_26/foreground_response/nonlinear_check/summary.json) has six unique SNe and both noiseless-reference and actual-observed targets: all 12 baseline/alternative pairs (24 fits) have optimizer success. Maximum nonlinear-minus-linear standardized shift is 7.38e-8 mag for noiseless targets and 7.92e-6 mag for observed targets. Maximum reported optimizer optimality is 2.15e-4 in the alternative fits. The generation code asserts success but has no separate optimality threshold; the saved linearization discrepancy is the more direct local check. It does not validate retraining, changed accepted epochs, classifier selection, BBC, or survey-wide transport.

No source edit is indicated by these checks. The map is an externally specified alternative, the stellar branch is conditional on incomplete release execution provenance, and neither establishes a physical dust or calibration bias. The verification script is [calibration_verify.py](../code/calibration_verify.py); rerunning it requires a new output directory because it refuses to replace the saved checkpoint.

## Frozen calibration-pattern refit: second-start check

The later [calibration-pattern refit](https://github.com/sprajs/cosmology-revalidation/blob/17487bf659fcbdeeea072221492bac14b04a0a85/runs/research_2026_09_26/calibration_pattern_refit/summary.json) also passed an independent numerical check, saved separately in [calibration_pattern_verification](https://github.com/sprajs/cosmology-revalidation/blob/17487bf659fcbdeeea072221492bac14b04a0a85/runs/research_2026_09_26/calibration_pattern_verification/summary.json). Its original source, input and output hashes still match its manifest. The observed-magnitude change `[+0.005228, -0.007837, -0.019265, +0.021873]` mag on `[g,r,i,z]` is exactly the **negative** of the frozen gray-free residual-dimming vector. For positive diagonal flux scale `S=exp(-K Δm)`, the transformed covariance is `S C S`; direct Cholesky of that matrix agrees with `S chol(C)` to 3.6e-15, and the two whitened-residual expressions agree to 4.3e-15. The local compensation sign is `J Δθ = -K f Δm`, consistent with the saved Fisher response.

All six original baseline/alternative fit pairs were repeated from the distinct start `[0.05, 0.25, 0.03, 2.0]` in the fitted amplitude/stretch/colour/time coordinates. All 12 second-start fits succeeded. Relative to the original fits, the largest standardized-shift difference is 1.06e-7 mag and the largest χ² difference is 6.7e-12. At `z=0.96937`, CID1339232 still shifts by `+0.17887034` mag while residual χ² changes by only `-0.00797`. This is **weak identification under a hypothetical frozen correction**, not evidence that the data require a 0.179-mag calibration bias. The [verification code](../code/calibration_pattern_verify.py) and its manifest preserve the original run untouched.
