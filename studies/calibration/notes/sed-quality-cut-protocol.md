# Frozen DES colour/shape cut probe

> Supporting research note. Scientific findings and limitations are preserved from the recorded investigation; historical result links identify the evidence available at that time. See the [study guide](../../README.md) for current execution status.

This protocol is frozen before computing any cut-change outcome. It is a retrospective, fixed-cohort eligibility probe for the 1,020 DES objects and 39,606 accepted epochs in the resolved full nonlinear validation. It is not a rerun of DES discovery, classifier, SALT3 fit errors, BBC bias corrections, or cosmology.

## Authoritative cut and input mapping

The DES-SN5YR paper, section 5.1 and Table 4 (local `papers/text/2401.02945v2.txt`), states strict `-3 < x1 < 3`, `-0.3 < c < 0.3`, `x1ERR < 1`, `PKMJDERR < 2`, and `FITPROB > 0.001`, with earlier detection/host-redshift requirements and later valid bias correction/common-systematics membership. The released `sources/repos/des-science__DES-SN5YR@1.3/7_PIPPIN_FILES/base_files/bbc/BBC_des5yr.input` gives `x1min=-3`, `x1max=3`, `cmin=-0.3`, `cmax=0.3`, `CUTWIN x1ERR 0 1`, `CUTWIN PKMJDERR 0 2`, `CUTWIN cERR 0 1.5`, `CUTWIN FITPROB 0.001 1.1`, `zmin=0.025`, `zmax=1.2`, and `chi2max=16`. `D5yr_analysis.yml` NOMINAL BIASCOR points to this BBC base with `chi2max=16`. These are published/release-configured rules, not a claim to have replayed the exact historical BBC executable. Boundary equality is excluded for the two cut coordinates, as the paper explicitly states strict inequalities; any exact-boundary input will be listed.

The cohort is exactly `runs/research_2026_09_26/astra_design/validation1020/cohort.csv`, by string CID and in its existing order. Every CID must join uniquely to released `4_DISTANCES_COVMAT/DES-SN5YR_HD+MetaData.csv` with IDSURVEY=10 and to `validation1020/objectives/objective_<CID>.npz`. Each objective contains unrounded `parameters_x0_x1_c_t0`, indexed `[x0,x1,c,t0]`, and the existing native accepted rows. The resolved `sed_nonlinear_validation/resolved/paired-responses.csv` must contain exactly one `target=observed_flux` record for each CID and each `mode=observer,sed`, each with a passing paired gate and four finite `baseline_theta`, `alternative_theta`, `actual_shift` coordinates. The model implementation in `scripts/research_2026_09_26/sed_nonlinear_refit.py` sets fitted x1=`native_x1+theta[1]` and c=`native_c+theta[2]`; verify `alternative_theta-baseline_theta=actual_shift` to 1e-10. Recheck the resolved manifest and object/refinement provenance before scoring.

## Prespecified arms and estimands

Use one shared 1,020-object row set, original accepted epoch masks and frozen model inputs. Do not refit, reclip, relabel, or add objects. The **exact native baseline** has theta zero and uses objective `native_x1,native_c`. The **observer** and **broadSED** arms use the resolved `observed_flux` full nonlinear alternative coordinates, `native_x1+alternative_theta[1]` and `native_c+alternative_theta[2]`. As a mapping diagnostic only, report the observed-target nominal optimum from `baseline_theta` separately; do not substitute it for the exact native baseline. No native-noiseless arm is planned.

Primary retrospective colour/shape eligibility for each arm is `(-3 < x1 < 3) and (-0.3 < c < 0.3)`, using identical strict thresholds. Report shape-only, colour-only and joint eligibility and exact equality counts. All other published selection variables and decisions are fixed at their released values and historical membership; in particular do not update `x1ERR`, `PKMJDERR`, `cERR`, `FITPROB`, redshift, chi-square, detection, host redshift, classifier, valid bias correction, or systematic-variant membership. Separately audit the released metadata colour/shape rule and static numerical quality columns (`x1ERR`, `PKMJDERR`, `cERR`, `FITPROB`, `zHD`) with the documented thresholds, identifying any already-selected rows outside those proxy windows without excluding them. The released-input audit is not an alternative model arm.

For baseline to observer and baseline to SED, report pass→pass, pass→fail, fail→pass and fail→fail, and whether a failure is through x1, c, or both. Report observer-vs-SED disagreement too. Retain every transition CID, baseline/released/arm x1,c, frozen `zHEL`, `zHD`, and field in a machine-readable per-object table. Report total and transition counts by the ten literal DES fields and by fixed zHEL bins `[0.025,0.2)`, `[0.2,0.4)`, `[0.4,0.6)`, `[0.6,0.8)`, `[0.8,1.2]`; out-of-range values are their own bin and never removed. No significance testing, coefficient refitting, outcome-driven threshold change or extrapolation to excluded objects.

## Gates and independent check

Hash the protocol and named source files before executing the probe; preserve those hashes and the result/source hashes in its output manifest. Abort on duplicate/missing CIDs, a nonpassing observed-target pair, nonfinite coordinates, failed theta-shift identity, inconsistent nominal theta between the two modes, or mismatch between objective and cohort zHEL beyond 1e-5. Compare objective native coordinates to the validation FITRES native parameters for an independent mapping check if accessible. A separate short calculation must recompute the three strict-cut pass counts and the baseline→arm 2×2 transition matrices directly from the saved per-object CSV, without importing the probe’s functions. Document all limits: fixed selected subset, frozen errors/classifier/detection/rows, no BBC selection function or corrected cosmology, and no population claim from the hypothetical observer/SED means.
