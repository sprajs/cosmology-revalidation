# Spectral models and distance identification

A signed optical BayeSN adapter and bounded engineering checks are available. A completed real-data posterior with validated held-out near-infrared prediction has not been established. Conditional spectral tests must not be reported as an independent distance or dust measurement.

## Code and scope

BayeSN input preparation, geometry and reference-integral comparisons, bounded benchmarks and synthetic infrared substitution checks. Obtain the author implementation and weights separately.

The [source directory](code/) retains the original calculations. See the [execution guide](../README.md#execution) before running them: historical imports and relative paths are assembled into an isolated workspace, and some studies require additional data or native software. Source preservation does not certify that an incomplete experiment succeeded.
