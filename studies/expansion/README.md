# Expansion and geometry

Released-distance flat-ΛCDM inference agrees with Pantheon+. The anisotropic BAO inequality test is inconclusive (tail fraction 0.4166). The exploratory BGS contrast and prior-sensitive BAO-only CPL fits do not measure an independent present-day acceleration. An arbitrary achromatic luminosity evolution remains degenerate with supernova distance shape. Directional estimates must retain their selection and optimizer-boundary limitations.

## Code and scope

Distance likelihoods, reference-chain comparisons, directional fits, BAO release ordering, constrained projections and physical conservation checks.

The [source directory](code/) retains the original calculations. See the [execution guide](../README.md#execution) before running them: historical imports and relative paths are assembled into an isolated workspace, and some studies require additional data or native software. Source preservation does not certify that an incomplete experiment succeeded.
