# Selected-sample conditional sampler repair (26 September 2026)

> Supporting research note. Scientific findings and limitations are preserved from the recorded investigation; historical result links identify the evidence available at that time. See the [study guide](../../README.md) for current execution status.

The historical `primary_gaussian_tripp` run remains invalid. Its two chains were constant for all 1,000 draws, mean acceptance was approximately 9.76×10^-119, maximum tree steps were 1,023, and maximum R-hat was approximately 1.065×10^15. Zero divergences did not certify movement. Its original `INVALID_FOR_INFERENCE.json`, posterior files, and held-out files are retained without alteration; their scores must not be interpreted.

The fault was isolated to the compiled measurement-covariance projection in `scripts/phase2/hierarchy/conditional.py`. The original expression computed the stretch and colour derivatives as `-dx[:, indices] @ coef` and `-dc[:, indices] @ coef` inside a stack. On the pinned Python 3.12.14, JAX/jaxlib 0.6.2, CPU, 64-bit configuration, a closed-over 850-row derivative array gave compiled values and gradients inconsistent with eager JAX and explicit NumPy. At one fixed Tripp coefficient vector, the summed projected variance was 33.5192326 by NumPy/eager but 1226.065135 by the compiled original expression; the coefficient gradient changed from `[-88.5463, 13.1977]` to `[759.0324, 759.0324]`. Splitting the dot products into named values and negating the results restores NumPy value and gradient to floating-point precision. An independent reproduction narrowed the failure to closure-constant gather, negation, then dot; it did not require the stack itself. The empirical model and priors were not changed.

Reproducers and exact runtime settings are in `runs/research_2026_09_26/conditional/reproducer_real.py` and its JSON result. A simpler three-row example did not reproduce the failure, so the observed scope should be stated on the frozen data and pinned runtime rather than generalized to every JAX program. `all_models_audit.py` checks all nine registered model index sets, three coefficient draws, both host components, full compiled `components` and `predictive`, and explicit NumPy means, variances, Gaussian mixture log density and analytic variance gradients on all 850 training rows. The repaired code agrees throughout to less than 1e-8. The historical expression was numerically correct in these checks for `none`, `stretch`, and `colour`; it disagreed for every model with two or more selected features. This fault alone does not invalidate the three completed simple fits, but all complex historical outputs need new runs.

The runner now writes `convergence.json` and checks four chains, finite/nonconstant chains, R-hat ≤1.01, effective sample size ≥400, no divergences, mean acceptance ≥0.6, and no maximum-depth trajectories **before computing a held-out prediction**. If a gate fails, it writes `INVALID_FOR_INFERENCE.json` and a manifest, and does not create held-out scores. A short visible Tripp diagnostic (80 warmup, 100 draws per chain) demonstrated movement, no divergences, maximum 31 steps, and mean acceptance 0.974. A longer two-chain repair diagnostic (600 warmup, 1,000 draws per chain) had maximum R-hat 0.99945, minimum ESS 2,206, zero divergences, maximum 63 steps, and mean acceptance 0.934. These diagnostics predated the stricter four-chain final gate and are not the final registered comparison.

All new runs are in `runs/research_2026_09_26/conditional/`; each includes a fresh configuration and input/code hashes. The frozen cohort assertion still requires the same 1,063 objects and 213 fold-zero held-out objects in both input arms. All runs use one OpenBLAS and OMP thread and a single-thread XLA CPU setting. This is a descriptive predictor within a selected high-SNN sample. Its projected covariance is an approximation to conditioning on noisy finite-population predictors, and its coefficients or scores cannot identify physical dust, age, the parent population, or cosmology.

All 18 registered primary model/noise runs and all 15 registered Gaussian sensitivities now pass the stricter gate. Among primary runs, the worst maximum R-hat is 1.00128 and the smallest minimum effective sample size is 3,525; among sensitivities these are 1.00186 and 3,425. There are no divergences in any of the 33 runs, and the largest post-warmup tree has 63 steps. The original failed run's output hashes remain intact. All 18 primary manifests were rehashed against current inputs and outputs. The active fit used approximately 0.8 GB RSS, with serial execution and one BLAS/OMP thread.

## Frozen comparison protocol (recorded before reading score magnitudes)

Use the exact 213 frozen fold-zero CIDs in the same order for every run; reject duplicate, missing, or changed-field rows. Require identical held-out observed magnitudes among runs using the same refit arm; the recovered-mask arm can have different fitted magnitudes and is checked separately. Verify each run's output hashes and that the summary's score sum/mean equals the sum/mean of `heldout.csv` within floating-point tolerance. First require all 18 primary and all 15 registered sensitivity convergence gates. Compare each of the nine primary mean families to Tripp within **each** Gaussian and Student4 noise family as paired per-object log-density differences. Also compare Student4 minus Gaussian for the same mean model. Keep the preregistered model order in tables; inspect score magnitudes only after validation. The score estimand is the selected-sample apparent-magnitude log predictive density.

For each paired contrast, report the sum and mean on 213 objects, a 95% percentile interval for the *mean* from 10,000 paired object bootstrap resamples (seed 20260926), and a separate 10,000-resample DES field-block bootstrap interval. In the field bootstrap, resample the observed field labels with replacement, include all objects in each sampled field, and compute the object-weighted mean. Also report the range of leave-one-field-out object-weighted means and number of fields. Neither bootstrap includes calibration/systematic or model-selection uncertainty. Report approximate score-integration MCSE from the 20 within-chain batches: use quadrature of the two runs' stored total-score batch MCSEs for a contrast, and keep it separate from bootstrap intervals.

For four registered Gaussian sensitivities that retain the same fitted held-out magnitude (omission of training CID1307748 only, quoted covariance×1.20, EdS reference and de Sitter reference), compare each of Tripp, host and flexible against its own primary Gaussian fit on the same 213 test objects. Within each sensitivity, also compare host and flexible to Tripp. For the recovered-fit-mask sensitivity, compare host and flexible to Tripp within that arm and then compare those **model contrasts** to the corresponding primary-arm contrasts; do not compare absolute log scores across different fitted-magnitude targets. Report the same paired object/field uncertainty and score MCSE. These are stress checks, not post-hoc alternatives chosen by held-out performance. A higher conditional score does not identify a physical dust law, age evolution, a parent-population correction, or q(z).

## Registered descriptive comparison

`scripts/research_2026_09_26/conditional_scores.py` implements the protocol above. It rejects any missing/invalid convergence gate, bad input/output hash, CID/fold/field mismatch, target mismatch within a refit arm, nonfinite score, or summary/batch-score inconsistency before producing comparisons. It validated the same 213 objects in ten DES fields across all 33 runs, then wrote 51 paired contrasts and every contributing per-object difference under `runs/research_2026_09_26/conditional/scoring/`. The largest primary summed-score batch MCSE is 0.084 nat; the largest single-object batch MCSE is 0.049 nat. These are approximate posterior Monte Carlo errors, separate from object and field sampling uncertainty.
