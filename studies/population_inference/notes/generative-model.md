# Independent hierarchical population model — specification before data comparisons

> Supporting research note. Scientific findings and limitations are preserved from the recorded investigation; historical result links identify the evidence available at that time. See the [study guide](../../README.md) for current execution status.

The implementation in `scripts/phase2/hierarchy/` begins with an explicitly approximate likelihood for independently fitted, pre-BBC SALT observables. It will be checked against actual calibrated flux and forward simulations before claims about physical corrections. This is below corrected distances but still conditional on a trained SALT SED; it is not an independent detector-image reconstruction.

For each supernova, the model contains latent stretch x, intrinsic effective colour c_i, optional nonnegative effective dust E, host category H and luminosity scatter. Observations are y=(mB,x1,c) with a genuine fitted Hessian covariance V, not a matrix mixing MINOS errors with parabolic covariances. Redshift uncertainty, lensing/peculiar velocities, calibration, selection and contamination are separately specified extensions, not hidden in a second copy of the released MU errors.

The core mean relation is

`mB = mu(z) + M - alpha(z) x + beta_i(z) c_i + R_B(H,z) E + gamma H + delta_M(z) + epsilon_M`.

`x ~ Normal(mu_x(H,z), sigma_x)`, `c_i ~ Normal(mu_c(H,z), sigma_c)`, `E ~ Exponential(tau(H,z))`, and `c = c_i + E` define an **effective SALT-coordinate population law**. Real F99 reddening applied to a time-varying SED does not map exactly to this additive c or a fixed R_B. We therefore do not label fitted R_B as physical R_V. Source-verified simulations actually store intrinsic SIM_SALT2c and pre-dust SIM_SALT2mB; converting those to fitted colour/magnitude by c+E or m+R_BE without a simulated/refitted light curve is not exact.

Gaussian x/c_i/scatter can be integrated exactly, giving a 3D normal mean and covariance. Integration over exponential E also has an exact expression: with r=y-mean, u=(R_B,0,1), A=uᵀV⁻¹u and B=uᵀV⁻¹r-1/tau, multiply the Gaussian density by `sqrt(2 pi/A)/tau * exp(B²/(2A)) * Phi(B/sqrt(A))`. Independent adaptive quadrature verifies the implementation, rather than comparing two transcriptions of the same formula.

The G models instead use total colour as a Gaussian latent with a Tripp luminosity coefficient. G0/G1/G2 separate population drift from changes in standardization coefficients. D0/Dhost/DhostM/Ddrift separate an effective dust decomposition, host-dependent dust, an additional intrinsic host luminosity term, and dust drift. The exact registry and priors are in `inference.py`; all candidate models use the same observations/splits. A flexible empirical population alternative and physical forward-SNANA prescriptions will challenge the causal interpretation.

Redshift drift uses g=z/(1+z). Priors before real-data outcomes: M~N(-19.3,.6), alpha~U(.02,.35), beta_i/Tripp~U(.1,6), mu_x~N(0,1), mu_c~N(-.04,.15), sigma_x~LogNormal(0,.5), sigma_c~LogNormal(log(.07),.7), sigma_M~HalfNormal(.2). Host stretch shift~N(0,.6), host colour shift where used~N(0,.08), intrinsic luminosity host term~N(0,.15). Population stretch drift~N(0,2), total-colour drift~N(0,.25), alpha drift~N(0,.15), beta drift~N(0,1.5). Effective dust R_B low/high each~U(1,6), tau~LogNormal(log(.08),.7), log host tau ratio~N(0,.7), log tau drift~N(0,1). These are explicit regularizing assumptions; sensitivity is required before physical interpretation or evidence ratios.

The selected likelihood is `p(y|z,H,selected) = p(y|z,H) epsilon(y,z,H) / integral p(y'|z,H) epsilon(y',z,H) dy'`. A complete-data mode is permitted only for an actually specified complete/synthetic population, not automatically for DES. A synthetic probit-in-observed-magnitude selector has an analytic Gaussian/ex-Gaussian normalization and is used solely for validation. The code refuses unknown real-survey selection modes. DES requires its actual trigger, host-redshift, quality-fit and classification selection, or a demonstrably valid approximation with sensitivity and recovery checks.

Mixture over uncertain binary host membership uses full component densities and selection probabilities. Plugging a fractional host into a hard-step relation is a different approximation. Host-category probabilities inferred from summary masses remain conditional on those mass estimators and their error model. Missing host colour errors are not zero uncertainty.

For population comparison, a flexible distance curve is common to all candidates so that an imposed LCDM shape does not choose the correction. For acceleration, implementations include `q(z)=q0+q1 z/(1+z)` and four piecewise-constant q bins with positive H obtained by integration. Constant-q analytic distance limits and the q=0 derivative are tested. q0~U(-2,1.5), q1~N(1,2); q bins~U(-2,2) with an explicit adjacent-difference regularity scale. Flat geometry and distance duality are assumptions; the first finite bin is not an instantaneous measured q(0). Arbitrary luminosity drift remains degenerate with distance shape and must not become falsely identified through an unreported prior.

The fixed synthetic benchmark records its parameters and selection before generation. Recovery and deliberately incorrect-selection analyses precede real outcomes. Fixed object-level folds use a deterministic hash of original survey+CID; duplicate observations stay together, and field/depth and redshift transfer are separate diagnostics. Scientific selection/likelihood shortcomings will be retained even if a sampler converges.
