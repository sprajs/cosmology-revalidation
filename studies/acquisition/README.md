# Acquisition and source identity

A reproducible input must identify its release, bytes and scientific role. A current URL or similarly named file is not enough to replace a missing historical product. Generated exports require the recorded preparation code, not an invented substitute.

## Code and scope

Public-source downloaders, catalogue construction, LFS hydration, extraction and integrity records. This directory contains our acquisition code, not downloaded software or papers.

The [source directory](code/) retains the original calculations. See the [execution guide](../README.md#execution) before running them: historical imports and relative paths are assembled into an isolated workspace, and some studies require additional data or native software. Source preservation does not certify that an incomplete experiment succeeded.
