# Physical identities and approximation limits

The physical checks separate conservation identities from approximations and empirical supernova models. Radioactive heating, diffusion and a blackbody limit provide controlled calculations; SALT surfaces do not constitute an explosion model or a physical luminosity standard. The current physical derivations are in [physical foundations](../../docs/physics/README.md).

## Code and scope

Radioactive-chain and diffusion calculations, Planck integration, observation-chain invariants and model-support checks. Cosmology and extinction checks are filed with their scientific topics.

The [source directory](code/) retains the original calculations. See the [execution guide](../README.md#execution) before running them: historical imports and relative paths are assembled into an isolated workspace, and some studies require additional data or native software. Source preservation does not certify that an incomplete experiment succeeded.
