# Dust and colour

In 71,946 written simulated supernovae, the historical prescription gives negative A(8000 Å) for 4,601 objects; exact F99 at the same stored parameters gives 4,791. This violates a passive-screen interpretation in that extrapolated domain. It does not measure the final survey-selected distance bias. Dust, intrinsic colour and calibration responses can be collinear; no bias-free correction or global bias bound has been established.

## Code and scope

Extinction source comparisons, physically allowed support, broadband response, simulation stress, and covariance propagation. The retained studies distinguish systematic-only covariance from total covariance or precision, avoiding duplicate statistical variance.

The [source directory](code/) retains the original calculations. See the [execution guide](../README.md#execution) before running them: historical imports and relative paths are assembled into an isolated workspace, and some studies require additional data or native software. Source preservation does not certify that an incomplete experiment succeeded.
