This protocol follows the already observed pilot/common-classifier covariance gap. It is an adaptive mechanism diagnostic, not pristine validation, a physical-null significance test, or an inferred correction to real photometry. All prior results and the ongoing full archived-fit holdout remain unchanged. No residual score from the rho000/rho090/noisetrue120 variants has been used in this design. ## Fixed scores, selection stages and transport

For every scored object retain projected chi-square Q_i, dimension n_i−4, matched product M_i, information I_i and G_i=M_i−I_i/2 for the unchanged real exact43 vector. Retain the same covariance-component trace allocation if feasible from exported COVSET; do not alter C. Main noise contrasts are rho000−nominal and rho090−nominal; noisetrue120−nominal is a declared secondary amplitude-of-noise intervention. No expected sign is imposed or used to select an outcome.

Report three distinct estimands, never merging their interpretations:

1. **Fixed common native-success cohort:** same physical objects in all four arms, each with its own freely fitted coordinates/mask. This measures the combined effect of the known noise intervention and nuisance fitting/clipping, conditional on the frozen all-four archived-fit cohort.
2. **Arm-specific archived basic quality plus new common classifier:** within the frozen cohort, apply each arm's own archived quality and pIa>.999. This deliberately permits membership changes. Show counts/flips by attempt, all-stage unweighted summaries and the supported-cell comparison. It assesses selection response in this conditional experiment, not survey selection-normalized cosmology.
3. **All-four quality/classifier intersection:** identical retained objects and equal per-object/cell weights across arms; label this selected common-object stratum. It helps separate within-object score response from composition change but cannot identify a general population causal effect because membership conditions on all four outcomes.

For each estimand, primary transport is the existing field/z bins; secondary adds measured SNRMAX1<15 or>=15 using each arm's archived fit and the unchanged real validation FITRES. For the all-four common-object comparison and its SNR sensitivity, fix transport cells using the NOMINAL measured SNR, so an object remains in one paired stratum; for arm-specific selection use each arm's own SNR as before. Keep only cells with at least two objects in EVERY evaluated arm and nonzero real1006 target count. Weights are real target-count/arm-count within the supported cell. The common-object comparison uses identical weights; arm-specific selection can have different weights. Report support fraction, weighted sums and effective sample sizes. Real scores on exactly the same cells are contextual, with no new real p-value.

The pooled dispersion statistic is sum(w Q_i)/sum(w(n_i−4)), not mean object reduced chi-square. Report amplitudes sum(w M_i)/sum(w I_i), original gains, band/phase/epoch coverage and covariance trace fractions. Do not interpret changed information or gain alone as disappearance/appearance of a signed pattern.

A predeclared mask sensitivity takes the intersection of accepted raw-PHOT epoch identities across all four arms within each common successful object; duplicate epochs require stable occurrence/raw-row identity. Use each arm's marginal C submatrix and fresh nuisance projection on exactly that common mask. Record all objects losing rank or information, without replacement. This isolates changed epoch inclusion from the remaining noise/fitting response and does not modify any primary mask.

Use1000 paired LIBID-block resamples with seed26092694, identical block multiplicities across all four arms, fixed support/weights and no reselection. Save paired differences in pooled Q, M/I and mean G relative to nominal. These intervals describe one coupled stored catalogue's Monte Carlo variation. They are neither a calibrated physical-null confidence statement nor independent-seed coverage. No multiple-testing adjusted detection claim is made.

## Failure criteria and interpretation

Fail or qualify the controlled-intervention interpretation if input/latent/cadence identity, exact masks/units/coordinate gates, arm-specific selector closure or adequate common support fails. Save failures before narrowing any scope. A strong response to rho or true-noise amplitude proves sensitivity to that simulated mechanism under this population/cohort; it does not establish the true survey rho, a wrong quoted error, new calibration bias or a cosmological distance correction. Lack of response does not validate real error estimates or rule out population/selection/SED alternatives.

The already audited full26518 selection ledger remains separate: rho000 gains32 archived-quality objects net, rho090 loses32, noisetrue120 loses87 versus nominal. Those source-ledger facts motivated this mechanism test but are not new residual results. No inference from negative passive attenuation is permitted; the common P21 truth-support label is shared across the paired arms and must be retained, with the same nonnegative2800–8000A grid sensitivity as the earlier pilot. Do not clamp or resample truth.
