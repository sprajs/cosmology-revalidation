# Supported noise/covariance diagnostic after the common classifier

This is a post-pilot diagnostic frozen before reading the newly common-classifier-selected residual aggregates. It preserves all primary model fluxes, coefficients, accepted masks and covariance. It tests comparability of the conditional residual/noise design; it does not renormalize errors, subtract a model covariance, or define a new physical-null significance.

Use the existing frozen pilot native scores for both laws. Main stage: archived basic quality AND the newly common reconstructed pIa>.999 selection, versus the fixed real1006 intersection. Also report the unchanged all-success and archived-quality stages as descriptive context. On each stage use the existing fixed field/redshift cells, the >=2 objects in BOTH P21/G10 rule, and the declared SNRMAX1=15 secondary split. Apply identical supported cells to the real and both simulated populations. Preserve unsupported counts rather than extrapolate. All selected-cohort decisions and memberships are sourced from the common classifier's frozen protocol, not residuals.

For each population calculate pooled weighted Q=sum(w_i chi2_perp_i)/sum(w_i nu_i), where nu_i=n_i−4, using real target-count/simulation-count cell weights and uniform real-object weights on the same support. Do not average individual chi2/nu ratios as a substitute. Save sums, counts, weighting effective sample size, epoch/phase/band coverage, per-object chi2/nu quartiles and the original fixed-vector M/I/gain. The existing1000 shared LIBID resamples may describe simulated Monte Carlo variability with frozen support/weights; they are not a calibrated confidence interval for the physical difference. No real p-value is introduced.

Audit the native covariance ingredients at the same object coordinates. The output PHASE2_COVSET columns are MW flux error, model covariance magnitude error, previous-iteration model flux, data flux error, and fudge flux error (SNANA-audit-v3/src/snlc_fit.F90 around10750). Check source/options for data off-diagonal COVFUDGE_DATA before identifying components. Known diagonal measurement/fudge and local MW outer product can be separated algebraically; label C minus verified known terms as a remainder until the source proves its content. Retain any indefinite component or numerical closure failure as a finding; do not force positivity or rescale it. Covariance uses a frozen iteration and is not automatically the final fitted mean's covariance.

With the unchanged tangent projector P=Qperp^T L^-1, report component trace tr(P C_k P^T) and their sum versus residual dimension. These are conditional design allocations, not estimates of true physical variance after fitting/clipping/selection. If a component cannot be exactly isolated, report the combined remainder instead of silently using an approximate substitute. Real and simulation covariance files may be read for this diagnosis; no C is changed for scoring.

Trace generator inputs and source for FLUXERRMODEL_SIM, SMEARFLAG_FLUX/ZEROPT, P21 dust/scatter and G10 wavelength scatter, then trace fitter SALT error maps/color dispersion/MW/data terms. Applying model scatter during generation and its predictive covariance during fitting is not by itself double counting. A duplicate physical allocation can be claimed only with explicit source semantics showing the same random component already entered quoted measurement error and was added again. Existing SIM and DATA/FAKE noise recipes and selection paths are distinct and must be kept separate.

The already seen pre-classifier unweighted pilot ratios (~.726 P21 and.704 G10 after archived quality, versus.905 for the full real target) motivate this audit but are not a supported same-cell comparison or proof of erroneous noise. Reporting a closer match after additional conditioning must not hide support loss. Any later error-model revision requires a separately justified measurement test and new frozen protocol.
