This study estimates a conditional timing effect using 64 new native noise realizations at the same fixed physical configuration as the completed engineering gate. Seed 26092672, sample size, cadence, source model, gates and estimands are fixed before generating any new photons. The eight engineering draws are excluded from every reported 64-draw summary.

For each draw, the nominal joint grizJH fit estimates distance and peak while shape and AV remain fixed. The NIR fit is then repeated on precisely the same six signed J/H measurements with either the true peak or that joint fitted peak rounded once to the native R4 coordinate. Only the HEAD peak bytes change. This preserves correlation between timing, NIR noise and the quoted error, including the native realized-flux variance adjustment. The comparison does not replace estimated timing by an independent Gaussian smear.

The primary per-draw quantities are assigned-peak error η in days, true-peak distance error e₀ in magnitudes, fitted-peak distance error e₁, and paired change Δ=e₁−e₀. We report means, sample standard deviations, Monte Carlo standard errors of means, raw second moments, the complete sample covariance matrix and pairwise crossmoments. Crossmoments involving η and distance have day·mag units. Covariance Monte Carlo errors use a specified delete-one jackknife; the other mean/moment errors use sample SD divided by √64. These are finite-sample Monte Carlo uncertainty estimates, not guarantees of Gaussian sampling or an uncertainty on survey cosmology. Internal peak precision and R4 quantization are retained separately.

The comparison generator repeats the exact same new seed solely to verify that output-only ledger hooks leave every native HEAD/PHOT column unchanged. There are 128 native generation attempts but only 64 unique stochastic science draws. Every generated event and epoch, including negative fluxes, enters the ledger. No missing or failed event can be replaced, reseeded or omitted. A failed support, convergence, identity or resource gate stops downstream estimation; a successful subset is not a substitute sample.

The deterministic noiseless control and compiled binaries are reused because their physical inputs and code are identical. Reuse additionally requires every new draw's source R8 mean and true variance components to match the engineering reference at the same physical exposure. The first eight stochastic fit errors or paired responses are never used as 64-draw outcomes. All 64 events receive the same 9/12 iteration, actual MINUIT ±2 peak-start, NIR ±0.2 distance-start, fixed-domain support and exact null checks. There is no response-size threshold or objective-based choice of optimizer branch.

The experiment still conditions on one cadence, one redshift, one template/shape/dust configuration and one native noise prescription. The trained empirical SNooPy model and calibration remain assumptions. Survey selection, intrinsic population scatter and the creator of observational peak headers are absent. Thus a mean e₁−e₀ would quantify a conditional simulation effect at this specified point; it would not yield a selection-normalized correction for the published RAISIN sample or a corrected cosmology. The separate original 1,536-draw proposal and all earlier failed branches remain unchanged.

The planned native sequence consists of two generation runs followed by four joint and nine NIR fits. Measured engineering runtime for the 13 main fits was 19.071 seconds; linear scaling gives roughly 153 seconds for 64, before unpredictable optimizer variation. Caps are 120 generation seconds and 600 fitter seconds, 90 seconds per process, one worker, and 2 GB each for output and process RSS. Plain logs are retained. Validators retain compact final/entry state between controls instead of accumulating complete histories. The output forecast is roughly 1.25 GB. These limits were set before the new outcomes.

Separate private generator and fitter search registries avoid ambiguous historical versions and shared-registry mutation. Native paths use phase2/pt64 and the existing short binary paths. The generator's source MXPATHLEN is 300; planned canonical working directories are 208–213 characters, while actual output and environment paths are shorter. The existing safe documentary README adapter and exact raw-byte peak adapter are reused. No Astropy table serialization is used for the intervention.

Implementation: `run.py`; scientific protocol: `protocol.json`; exact hashes: `freeze.json`; read-only preflight: `preflight-result.json`. The generation, joint and NIR stages each require a root release binding the protocol and freeze hashes. Preparation made no native calls.
