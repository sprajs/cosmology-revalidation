`max_i[t_i−(1+z)b_i] ≤ peak_absolute ≤ min_i[t_i−(1+z)a_i]`.

Table support remains weaker than empirical model validation.

The exact frame and precision matter. `FCNSNLC` uses R8EP_MJD, populated from SNLC8_MJD, and divides observer time differences by1+zHEL. The FITS MJD1D column must remain double. `MJDOFF` is zero in these files, but a general implementation must subtract MJDOFF from both absolute bounds before setting the internal peak parameter. R4 mask-time arithmetic is a separate route: endpoints must be tested in both the mean and mask calculations. The review script finds no inward shift needed for the current R8 operation order; any required numerical inward adjustment must be the smallest representable safe value, recorded in days, not an arbitrary phase buffer or a relaxed cut.

Native source does not expose a general peak-bound NML. `FITINI_PARVAL` in `snlc_fit.car:8060–8073` hard-codes initial±100days; OPT_DEBUG30 changes it to±30, which still does not respect this domain. `MNFIT_DRIVER` in `snana.car:36586–36590` passes INIBND directly into MNPARM, so a narrowly isolated source hook can define the desired hard MINUIT parameter limits. The limits must be fixed from the same complete physical cadence before the first model evaluation and retained across iterations, independent of the recentered peak prior. Both the prior and covariance iteration remain otherwise native; this is not a prior-free Gaussian maximum-likelihood estimator.

The minimal implementation should have three explicit protections:

- A default-off private hook, called when the first-iteration peak INIBND is initialized and before FITINI_ADJUST, computes or validates the same physical-domain bounds from the actual input time metadata and loaded model/table limits. It logs exact bounds, active rows, frame, MJDOFF and source-table identity. Its disabled path must reproduce existing source/binary behavior exactly. Its enabled path changes peak bounds only. Empty intersections, nonfinite metadata or out-of-domain starting parameters abort before mean evaluation; there is no clipping.
- Initial-grid and continuous-search paths must obey that domain. The current source grid is initial±4days and the declared alternative starts are±2days, so all15 prescribed start/grid coordinates already lie inside this specific interval. Native MNPARM bounds protect its internally transformed MINUIT trials and numerical gradients. `FCNCHI2_PRIOR` also rejects parameters outside INIBND, and FCNSNLC returns early for their large penalty before the mean loop. That guard alone is insufficient: SIGMA_ONLY skips the prior and other routines call USRFUN directly.
- An unconditional enabled-mode domain check immediately before any physical USRFUN/model/KCOR evaluation must stop an unsafe direct, covariance, derivative or diagnostic call. It must not return a clipped phase, a fabricated flux or a silently dropped epoch. Keep the existing all-call summary as an independent audit. Rest-frame auxiliary calls must be checked using their actual rest phase rather than incorrectly compared to an observer peak bound. No unsupported physical evaluation is permitted, even when the final fit would be valid.

A bounded engineering protocol would first inspect/test endpoint arithmetic and the disabled hook without producing new photons, then separately freeze and replay the existing noiseless control and all eight stochastic records through this newly named estimator. The old results remain immutable. Required gates are unchanged: full membership and same signed PHOT data/error pairs, exact fixed nuisance/peak interventions, all-call support,12-versus9 and prescribed starts, final covariance convergence, amplitude stationarity and pure null identity. Also record distance to each peak boundary and whether the optimum or its uncertainty exploration touches a boundary; a boundary result is not an unconstrained timing measurement. The four-day final guard remains a diagnostic gate, not a new truth-centered parameter limit. No posthoc removal of CID4/7, no covariance/Q winner and no larger sample until the revised estimator passes.

No source patch, build or native fit is authorized by this proposal itself. Source review and the metadata-only intersection are saved alongside the failed-branch ledger. The separate64-new-draw plan should only be frozen after this estimator's engineering gates close, with a new predetermined seed and without using the eight paired effects to choose sample size, truths, bounds or stopping.
