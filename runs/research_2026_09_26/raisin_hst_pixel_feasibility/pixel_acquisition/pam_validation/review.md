# WFC3/IR area-map and distortion-reference validation

The exact current public FLT header reference `iref$w3m18525i_idc.fits` was acquired from [STScI CRDS](https://hst-crds.stsci.edu/unchecked_get/references/hst/w3m18525i_idc.fits) (20,160 bytes; SHA-256 `4c39ed49ac5ca1c4d24accecbbea19d72f1a628c4a7d115286933104540b7c34`). It identifies WFC3/IR distortion coefficients, `USEAFTER` May 11 2009, dated March 2012, and contains a forward F160W solution. The [WFC3 Instrument Handbook distortion inventory](https://hst-docs.stsci.edu/wfc3ihb/appendix-b-geometric-distortion/b-1-overview) independently identifies this IR IDCTAB. The official [STScI WFC3 pixel area map](https://www.stsci.edu/hst/instrumentation/wfc3/data-analysis/pixel-area-maps) `ir_wfc3_map.fits` was acquired from its linked URL (4,121,280 bytes; SHA-256 `6661d199912dbf0ceccae094ec3b647529e16cee2749337f3a440ed71d928163`). Both download identities, HTTP metadata and byte caps are in `acquisition.json`. No science image plane was opened for numerical analysis.

The PAM is a 1014×1014 single image extension labeled `WFC3/IR PIXEL AREA MAP`; its header has no explicit `BUNIT`. The [WFC3 Data Handbook §9.1.2](https://hst-docs.stsci.edu/wfc3dhb/chapter-9-wfc3-data-analysis/9-1-photometry) defines PAM values as normalized detector-pixel area and says to **multiply** FLT/FLC count-rate pixels by the PAM for point-source aperture photometry. DRZ/DRC products have already undergone distortion/area correction. The handbook distinguishes a FLT×PAM aperture correction from the aperture correction for a drizzled image; this task does not apply either to a source.

All eight acquired F160W FLTs are full-frame `FULLIMAG`, trimmed 1014×1014, with SCI `LTV1=LTV2=0`, `LTM1_1=LTM2_2=1`. The declared direct index mapping is therefore FITS `(x,y)` to PAM array `[y−1,x−1]`, without a subarray offset or 5-pixel shift. Their SCI WCS is TAN-SIP with fourth-order distortion, linked by `SIPNAME` to `w3m18525i`; the exact IDCTAB is available. The current reference files and 2026 FLT WCS are not evidence for a historical private RAISIN reduction.

The derivative uses each exposure's full sky WCS in native detector `(x,y)` order and a spherical solid-angle determinant, so telescope roll/orientation is included without rotating or transposing the detector-fixed PAM. The area is taken as an absolute determinant; the PAM and Jacobian are divided by their respective values at the same center pixel. This is a relative-shape test, not an independently calibrated absolute pixel solid angle.

The comparison protocol and executable were hashed in `prescan-hashes.txt` before numerical comparison. On the predeclared 11×11 grid at both axes `[50,141,233,324,416,507,598,690,781,873,964]` (121 detector positions in each of eight FLTs), the official PAM and the native TAN-SIP spherical area Jacobian were each normalized at `(507,507)`. No scale, axis choice or offset was fit. Across all 968 points, the median absolute relative discrepancy is **9.56×10⁻⁵** and the maximum is **7.82×10⁻⁴**. Halving the symmetric Jacobian step from 0.5 to 0.25 pixels changes normalized areas by at most **4.56×10⁻⁹**. The PAM center value is `0.9958127141`, with sampled grid range `0.9571824670–1.0347979069`; these are calibration-map values, not measured scene brightness. `result.json` retains every file/grid discrepancy and all header hashes.

The geometry is sufficiently cross-checked for a *conditional current-product* FLT aperture/noise design using the official PAM directly. The residual PAM–WCS mismatch remains explicit; it should not be forced to zero by a fitted normalization beyond the declared center ratio. Historical RAISIN AstroDrizzle/subtraction settings, masks and effective calibration files remain separate provenance questions. No SN/sky flux, image noise or physical outcome was computed.
