# Frozen implementation of the P21/G10 residual score

Written after the four full native fits passed the source, membership, epoch, flux, covariance and tangent gates, and **before simulated residual scores were computed**. The scientific protocol is the hashed `astra_design/simulation-residual-protocol.md` plus `simulation-law-clarification.md`; this file records only implementation choices. No residual cut or coefficient is selected from simulated outcomes.

For each object in the intersection of its two laws' accepted FITRES rows and closed native objective exports, order accepted epochs by MJD then band. Use native fitted x0/x1/c/t0, native model flux f and covariance C, and the unchanged `flux_response.analyze` independent shape/color/time tangent with its amplitude column replaced by exact native `-0.4 ln(10) f`. Let L Lᵀ=C and W=L⁻¹J. Require numerical rank four at singular threshold s0×1e−10. Let Q be the left singular complement, r=QᵀL⁻¹(y−f), and three observer columns be QᵀL⁻¹ times `-0.4 ln(10) f` in g−r, i−r, z−r basis, respectively (the code's original order is g−r, i−r, z−r). Read frozen c from `validation1020/frozen-discovery-coefficients.npz`; save u=Tᵀr and F=TᵀT. Per object a=cᵀu, I=cᵀFc, G=a−I/2. Preserve the native zero-model epochs in r, C and tangent; never substitute the independent mean. Astra's separate native finite-difference check quantifies tangent approximation on declared engineering cases, without asserting a global bound.

Primary stages: every common two-law accepted FITRES/objective CID, then the subset whose **archived** `basic_quality_pass` was true. A new-fit basic-quality subset using the existing `forward_summary.py` formula is separate fit-closure sensitivity. The declared P21 `nonnegative_declared_grid` truth subset is secondary, alongside all full-cohort values, and never called physically validated. G10 -9 AV/RV values are no-explicit-screen sentinels. All stage rows keep native failures and counts upstream in the fit ledgers.

Transport bins are the frozen z edges [.05,.2,.35,.5,.65,.8,1.2] and first-PHOT ten-field labels. For each arm/law/stage, a cell is supported only if at least two successful P21 **and** G10 objects occupy it. Sim object base weight is `n_real_cell/n_sim_cell`; real objects in supported cells have equal base weight. Normalize weights to sum one separately when reporting descriptive mean gain. Transported amplitude is sum(w a)/sum(w I). Report raw unweighted a/I/G, field contributions and real/sim support fractions. One secondary support split adds SNRMAX1<15 or ≥15, using the **archived simulation FITRES** value in each frozen cohort CSV and **validation1020/fit.FITRES.TEXT** for real target; those sources are hashed in the score input manifest. No support extrapolation. For P21 grid-nonnegative secondary recalculate support using the 242/256 frozen truth labels, retaining all original primary scores.

Draw 1,000 replicate arrays of unique `SIM_LIBID` blocks with fixed seed 26092691, sampling from the union of P21/G10 pilot blocks with replacement. Apply the same block multiplicities to both arms where a LIBID is shared; differing written/fit membership remains explicit. Keep original cell support and object base weights fixed. Recompute amplitude and mean gain with these multiplicities; record empty-weight or empty-information replicates as failures, report quantiles over successes and failure count. The interval describes finite realization/cadence-block uncertainty, not calibrated physical-null coverage.
