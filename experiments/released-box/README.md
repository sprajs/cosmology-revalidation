## Numerical route and limits

prepares the pinned Irreducible Gaussian/retained DesignProfile/GaussianBox

completion, covariance, determinant, tail, CDF and inverse-CDF mathematics belong
to Irreducible. No GaussianBox CLI operation is invented.

[controller.py](controller.py) admits the original source assets and exact
canonical bytes; snapshots clean committed Reproducible source; verifies the
SDK's source inventory, build, installed archive/CLI, compiler and standard
library; compiles this one native consumer; and retains its actual executable
identity. It validates closed typed output and causal stage/availability fields.
Earned diagnostics survive refusal; absent quantities stay null. Parsed child
output is bound to its captured bytes and hash, and terminal drift revokes
acceptance. Existing attempts cannot be overwritten.

[reference.py](reference.py) independently admits the original binary32 FITS
and exact binary64 transport, without reading native outputs or historical
fitted results. Full-C LAPACK Cholesky whitening feeds independent QR and SVD
completion algorithms. Original-C wide residual refinement and a separate
source-C eigenvalue determinant route calibrate numerical error; 80/120-digit
Decimal arithmetic concerns the reduced46 system and finite-box controls.
Those checks give empirical original-input error estimates, not a certified
inverse or original-C accuracy proof. QR/SVD share whitening and data ancestry;
method agreement supplies no observational independence. Conditional native
enclosures and empirical reference brackets are reported separately.
