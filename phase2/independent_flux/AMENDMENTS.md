# Evidence-led amendments

1. The first exact comparison exposed a portable-bundle error-map mismatch. SNANA stdout explicitly loads `salt3_lc_variance_0/1` and `salt3_lc_covariance_01`, while the initial bundle supplied `salt3_lc_model_variance_0/1` and `salt3_lc_model_covariance_01`. The latter are not identical. Initial results and source are retained under `initial_wrong_error_maps`; these covariance ratios are confounded and must not be interpreted as independent implementation differences. Corrected runs use the verified runtime files directly from the pinned public release, with hashes in every manifest. Mean assets were correct throughout.

2. Full-precision audit export showed that the time-prior centre is the preceding iteration's `INIVAL`, not the original search peak. Independent frozen-objective fits will use the exported centre. A smooth exact Gaussian prior is used; SNANA tabulates and linearly interpolates it on a 0.012-day grid. This introduces a small, explicitly retained objective difference.

3. The portable exact objective and published accepted masks contain 528 accepted observations across 12 SNe. The 628 count communicated during export was a transcription error; the independent row-ID match and array sizes establish the actual count.

4. Before synthetic outcomes: use seed 9212026, 10 independent correlated-noise realizations for each of 12 observed cadences, generated under the exported frozen covariance. Refit each realization under both the generating covariance and a native-sncosmo covariance using the same runtime maps and the same exported Milky Way term. These tests assess conditional optimizer/Hessian calibration, not which astrophysical covariance is true. Use 10,000 linearized draws per cadence for independent covariance propagation. A separate 12-object synthetic injection adds d=0.06 phase-colour with one noise realization per cadence, then compares baseline and flexible held-out prediction. This small injection test establishes sensitivity, not population detection power.

Noise sensitivity arms are registered before their outcomes: native-sncosmo covariance frozen at the official fitted parameters; independently constructed SNANA-formula covariance recomputed at trial parameters with its documented nonlinear magnitude-to-flux error conversion; native-sncosmo recomputed covariance. For each recomputed arm report both chi-square-only minimization and normalized Gaussian likelihood including log determinant. These objectives are not interchangeable. Held-out mean-family tests primarily use the common exported frozen covariance; a native frozen sensitivity repeats the identical epoch split.
