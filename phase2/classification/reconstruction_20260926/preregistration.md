# SNNV19 reconstruction preregistration (26 September 2026)

Written before opening or calculating any reproduced model probabilities or comparison outcomes. The public comparison file header has been inspected; the released probability values have not been analysed.

## Fixed inputs and method

Use the released DES-SN5YR_DES HEAD/PHOT FITS and only the 1,635 unique SNIDs listed in `3_CLASSIFICATION/DES_classification.csv`. SNANA `PTROBS_MIN/MAX` are inclusive, one-based PHOT pointers; exclude the end-of-object sentinel row. Apply the data-stage training job's PHOTFLAG rejection bits 8, 16, 32, 64, 128, 256, 512 by bitwise OR; retain all other flags. Replace `HOSTGAL_SPECZ` and `_ERR` with `REDSHIFT_FINAL` and `_ERR` on every observation. Supply raw MJD, BAND as FLT, FLUXCAL and FLUXCALERR to pinned `SuperNNova` onthefly inference (`fcf8584b64974ef7a238eac718e01be4ed637a1d`), using released SNNTRAINV19_z_TRAINDES_V19 model and normalization, CPU and eval mode. No time-window cut. The official pivot, 0.33-day grouping, minimum-error duplicate filter selection, filter ordering, one-hot features, float32 cast, `cosmo` normalization and packing are left to official source. Class 0 is Ia by `tag_type`; compare predicted class-0 probability with `PROB_SNNV19`. Keep native numerical results and full mismatch table. No tuning on released labels.

## Prospective checks and adequacy gate

Before inspecting public probabilities, validate unique HEAD SNIDs, all pointer bounds and counts, sentinel exclusion, no missing classifier IDs, finite retained flux/errors, and the retained/rejected observation counts. A deterministic fixed ten-SNID subset, chosen by lexicographically sorted IDs at indices 0, 1, 2, 10, 20, 50, 100, 200, 500, 1000, will be compared between one-object and combined onthefly inference; maximum absolute batch difference must be <= 1e-6. All 1,635 predictions must be finite and in [0,1].

Published probabilities have four decimal places. Report absolute median/95th/99th/maximum, RMS, signed bias, Spearman rank agreement, and exact >0.999 and >0.5 membership confusion counts. The reconstruction is **adequate for applying to forward simulations** only if RMS probability error <= 0.005, 99th percentile absolute error <= 0.02, Spearman rho >= 0.995, >0.5 membership agreement >= 99%, and >0.999 membership agreement >= 98%. Also report stricter rounded-release agreement (absolute error <= 0.00005) without requiring it for adequacy. Flag any mismatch rather than changing method to meet the gate. For descriptive diagnostics, bin signed/absolute differences by REDSHIFT_FINAL quartile, peak retained S/N quartile and retained-epoch-count quartile; no diagnostic bin is a selection criterion.

If and only if the DES gate passes, apply the identical method to all detected HEAD objects in nine already generated variants. Export separate per-variant CID, probability, >0.999 and >0.5 flags, raw/retained/rejected observation counts, redshift, and peak retained S/N. Report per-variant classifier acceptance by redshift quartile, with generated attempts kept separate from detected HEAD denominators. These scores are selection information from the same fluxes, not an independent likelihood and not interchangeable with simulation truth Ia.

If the DES gate fails, stop before nine-variant production; retain exact diagnostics and request parent direction. A declared cause diagnostic may inspect preprocessing and source behavior without fitting choices against the published probabilities.
